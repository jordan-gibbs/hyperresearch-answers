# Hyperresearch media kit

Charts, cards, logos, screenshots and a one-page fact sheet for editors, journalists and directory reviewers. Built October 31, 2026. Every number matches hyperresearch.ai/answers and hyperresearch.ai/benchmarks/draco.

Contact: Jordan Gibbs, founder, jordan@hyperresearch.ai. Company: Thalient Labs Inc., Kalispell, Montana.

All files are hosted. Link to them from email, or attach them. Base URL: `https://raw.githubusercontent.com/jordan-gibbs/hyperresearch-answers/main/press/`

## Benchmark method lines

- **BrowseComp**: 100 questions, October 2026, % correct. Details: hyperresearch.ai/answers
- **DeepSearchQA**: 100 questions, October 2026, % correct. Details: hyperresearch.ai/answers
- **DRACO**: 10 tasks (one per domain), the paper's per-criterion grader, GPT-5.2 judge. You.com Research, Perplexity Deep Research and Valyu DeepResearch Heavy were scored on 8 of the 10 tasks. Always cite it as "77.7 (10 tasks)". Details: hyperresearch.ai/benchmarks/draco
